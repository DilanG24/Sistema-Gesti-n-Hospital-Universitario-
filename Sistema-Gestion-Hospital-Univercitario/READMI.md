# Sistema de Gestión Médica

## Descripción

Este proyecto consiste en desarrollar un sistema de gestión médica utilizando Java y programación orientada a objetos. Su propósito es organizar la información de los pacientes, médicos y especialidades médicas.

## Objetivo

Aplicar los conceptos de programación orientada a objetos, como clases, atributos, métodos, encapsulamiento y relaciones entre objetos.

## Herramientas utilizadas

* **Lenguaje:** Java
* **Editor:** Visual Studio Code
* **Control de versiones:** Git y GitHub

## Estructura del proyecto

* `src/`: contiene el código fuente del programa.
* `docs/`: contiene la documentación del proyecto.
* `uml/`: contiene el diagrama de clases UML.
* `README.md`: información general del proyecto.

## Funcionalidades

El sistema organiza las clases y los objetos relacionados con la gestión médica. Las funcionalidades disponibles dependerán de los métodos implementados en el código.

## Diagrama UML

El diagrama de clases UML se encuentra en la carpeta `uml/` y representa las clases, sus atributos, métodos, modificadores de acceso y asociaciones.
